## 開始之前

三樣東西缺一不可：

1. **MT5 已經安裝，而且已經登入你的交易帳號**
2. **會員帳號密碼** —— 向管理員索取（IG `@goldyoung0927`）
3. **Hub 網址與密碼** —— 同上

還有一件事要先有心理準備：**這台電腦必須保持開機、MT5 保持登入。** 訊號來的時候程式要在跑才下得了單，關機或睡眠期間的訊號會錯過。

## 第一步：安裝 MT5 的 EA（最容易出錯的一步）

跟單程式不會直接操作 MT5，它是透過一個叫 EA 的小程式在下單。**沒裝這一步，程式裝好也不會動。**

### 1-1 找到 MT5 的資料夾

打開 MT5 →  上方選單 **檔案** → **開啟資料夾**

這會直接打開正確的位置。**不要自己去 Program Files 找**，MT5 的資料夾位置每個人不一樣，猜錯是最常見的失敗原因。

### 1-2 放進 EA

在剛打開的視窗裡進入 `MQL5` → `Experts` 資料夾，把 `MT5_File_Bridge_Enhanced.mq5` 複製進去。

這個檔案在哪裡拿：

- **Windows**：安裝完成後在 `C:\Program Files\黃金跟單會員端\_internal\mt5_ea\`
- **macOS**：在應用程式上按右鍵 → **顯示套件內容** → `Contents/Resources/mt5_ea/`

### 1-3 編譯

回到 MT5，按 **F4** 打開 MetaEditor → 左邊導覽找到 `MT5_File_Bridge_Enhanced.mq5` → 雙擊打開 → 按 **F7** 編譯。

下方訊息欄出現 `0 errors, 0 warnings` 就成功了。

### 1-4 掛到圖表上

回到 MT5 → 開一張 **XAUUSD** 的圖 → 從左邊「導覽器」的「專家顧問」把 `MT5_File_Bridge_Enhanced` 拖到圖上。

彈出的視窗裡：

- 勾選 **允許演算法交易**
- `TradingSymbol` 保持 `XAUUSD`（如果你的券商代號有後綴，例如 `XAUUSD.m`，改成你實際看到的）
- 其他保持預設

按確定。圖表右上角出現一個**笑臉**就代表 EA 在跑了。哭臉的話，檢查 MT5 工具列上的「演算法交易」按鈕是不是綠色的。

## 第二步：安裝跟單程式

### Windows

雙擊 `GoldCopyTrader-Member-*-Windows.exe`。

**會跳出藍色警告「Windows 已保護您的電腦」** —— 這是預期的。這個安裝檔沒有數位簽章（那需要每年付費的憑證），Windows 對所有沒簽章的程式都會這樣。

按 **其他資訊** → **仍要執行**。

然後照精靈一路下一步即可。

### macOS

1. 打開 `GoldCopyTrader-Member-*-macOS.dmg`
2. 把「黃金跟單會員端」拖到旁邊的 **Applications** 資料夾
3. **第一次開啟一定要按右鍵 → 打開**（不能雙擊）

   直接雙擊會看到「無法打開，因為 Apple 無法檢查是否含有惡意軟體」，而且**只有取消按鈕**。按右鍵打開才會出現「打開」選項。

   > 這同樣是沒有 Apple 開發者憑證的關係，不是程式有問題。之後就能正常雙擊了。

4. 如果按右鍵也打不開，出現「**已損毀，無法打開**」，打開「終端機」貼上這行按 Enter：

   ```
   xattr -cr /Applications/黃金跟單會員端.app
   ```

   這是把 macOS 對「從網路下載的檔案」加的隔離標記清掉。

## 第三步：第一次啟動

程式啟動後會自動打開瀏覽器，網址是 `http://127.0.0.1:某個號碼`。

> 這是跑在你自己電腦上的控制台，**沒有連到外面**，別人連不進來。

### 3-1 登入

輸入管理員給你的帳號密碼。

> 一組帳號同時只能在一台電腦使用。在別台登入會把這台踢出去。

### 3-2 填設定

按右上角 **設定**：

| 欄位 | 填什麼 |
|---|---|
| 雲端 Hub URL | 管理員給的網址 |
| Hub 密碼 | 管理員給的密碼 |
| MT5 Files 路徑 | **留空**（會自動偵測） |

按 **儲存設定**。

### 3-3 開始跟單

按右上角 **開始跟單**。

頂部三個燈號都要是綠的：

- **跟單運轉中** —— 程式在跑
- **MT5 已連線** —— 抓得到 MT5 的資料（沒亮 = 第一步的 EA 沒裝好）
- **訊號伺服器** —— 連得上 Hub（沒亮 = Hub 網址或密碼填錯）

三個都綠了就完成了。畫面上會開始出現黃金的即時報價和 K 線圖。

## 常見問題

**「MT5 已連線」一直不亮**

九成是 EA 的問題。依序檢查：

1. MT5 圖表右上角是笑臉還是哭臉？哭臉 → MT5 工具列的「演算法交易」按鈕要是綠色
2. MetaEditor 編譯時真的是 `0 errors` 嗎？
3. EA 拖到的是 XAUUSD 的圖表嗎？

**K 線圖顯示「等待 MT5 行情資料」**

EA 要跑滿約 30 秒才會寫出第一份 K 線資料。等一下再看。還是沒有的話同上，檢查 EA。

**週期只有 M1、M5 可以選**

你的 EA 是舊版。重做第一步，用新的 `.mq5` 檔重新編譯一次。

> 舊版 EA 只輸出 M1 資料，程式會自動合成出大週期，但根數不夠的週期不會給你選。

**訊號來了但沒有下單**

- 帳戶餘額夠嗎？保證金不足下不了單
- MT5 的「演算法交易」是綠色的嗎？
- 看畫面最下方的「狀態紀錄」，失敗原因會寫在那裡

**程式關掉之後還會跟單嗎**

不會。程式要開著、MT5 要開著、電腦不能睡眠。

想要 24 小時不斷，得把 MT5 和這個程式放在一台不關機的電腦或 VPS 上。

**電腦重開機後要重新設定嗎**

不用，設定會留著。安裝時如果有勾「開機後自動啟動」，重開機會自己跑起來。

## 換電腦 / 重新安裝

設定和跟單紀錄存在這裡，重裝不會被刪掉：

- **Windows**：`%APPDATA%\黃金跟單系統`
- **macOS**：`~/Library/Application Support/黃金跟單系統`

想完全清乾淨就手動刪掉這個資料夾。
