分批止盈與保本移損

一筆訊號帶多組止盈時，可以按比例分批平倉；也可以改成第一個止盈到價就把停損推到成本價，剩下的部位零風險續抱。每個來源各自選一種。

  • 分批比例自訂，例如 0.5 / 0.3 / 0.2
  • 保本移損模式：第一個止盈成交即移動停損
  • 兩種模式可以依來源分別設定

多訊號源獨立控管

每個訊號來源都是獨立的一組設定：跟或不跟、用馬丁還是均注、手數多少。停用的來源不佔版面，報表與統計也不會把它算進來。

  • 跟單開關、下單模式、手數，逐一來源設定
  • 停用的來源自動從版面與統計中移除
  • 尚未上線的群組可以先手動建好設定

每日風險上限

設定每天最多能虧多少（金額或本金比例），觸線就自動停手、當日不再開新倉。掛單超過設定時間還沒成交會自動撤掉，並同步通知 MT5 刪除委託。

  • 每日最大虧損可用金額或比例設定
  • 逾時未成交自動撤單，預設 3 小時
  • 撤單會同步通知 MT5，不會留下幽靈掛單
